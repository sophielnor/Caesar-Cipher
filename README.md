# Caesar Cipher 🔐

A simple and interactive Caesar Cipher tool built using **HTML**, **CSS**, and **JavaScript**. This project allows you to **encode** or **decode** text using the classic Caesar shift technique.

## 🔧 Features

- Encode or decode any text using a Caesar cipher
- Toggle between shift directions (+ / -)
- Adjustable cipher key (numeric shift)
- Supports both uppercase and lowercase letters
- Real-time output as you type

## 🛠️ How It Works

The Caesar Cipher shifts each letter in the input text by a specified number of positions in the alphabet. Non-letter characters remain unchanged.

For example:
Input: HELLO
Shift: +3
Output: KHOOR
